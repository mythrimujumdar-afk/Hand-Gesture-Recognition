# 👋 Hand Gesture Recognition System

**Author: Mythri Mujumdar**

A real-time computer vision project that detects and recognizes predefined hand gestures using a webcam. The project uses MediaPipe for hand landmark detection and OpenCV for real-time video processing and gesture recognition.

## ✨ Features

- 📷 Real-time webcam-based hand detection
- ✋ Hand landmark tracking using MediaPipe
- 🎯 Real-time gesture recognition
- ⚡ Smooth gesture detection
- 🖥️ Live display of recognized gestures
- 🤚 Supports multiple predefined hand gestures

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## 🤚 Supported Gestures

- Open Palm
- OK
- Thumbs Up
- Thumbs Down
- Peace
- Pointing
- Phone Call

## ⚙️ How It Works

1. The webcam captures live video.
2. MediaPipe detects hand landmarks.
3. The landmark positions are analyzed.
4. The system identifies the gesture based on the hand configuration.
5. The recognized gesture is displayed in real time.
